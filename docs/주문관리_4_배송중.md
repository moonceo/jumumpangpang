# 주문관리: 4. 배송중 (Shipping)

## 1. 개요
현지 운송장이 등록되어 물류 이동이 시작된 시점부터 국내 고객에게 배송이 완료될 때까지의 전 과정을 관리한다. 전체 리드타임 중 가장 긴 시간을 차지하며, **고객 문의 방어(배송 조회)**와 **물류 예외 대응(오류입고, 통관지연)**이 핵심이다.

*   **URL**: `/orders/shipping`
*   **핵심 가치**: 실시간 트래킹, 배대지 통합 관리, 통관 모니터링, 고객 문의 대응

## 2. 포함 상태 (Status Scope)
거의 모든 물류 단계를 포괄하며, 배송 완료 이후의 구매 확정 프로세스까지 관리한다.
*   **현지**: `현지 발송 대기중`, `현지 배송중`
*   **배대지**: `입고 대기`, `오류입고`, `입고중`, `견적 완료`, `배송비 결제 완료`, `출고 준비`, `출고 완료`
*   **국내/통관**: `국내 입항`, `국내 배송중`
*   **완료/확정**: `배송 완료`, `구매 확정 대기`, `구매 확정`

## 2. 데이터 테이블 명세 (Table Columns)
'공통 테이블' 구조를 따르지만, 배송중 메뉴 전용 칼럼 정의와 데이터 표시 방식이 적용된다.

| 컬럼명 | 데이터 및 UI 명세 | 비고 |
| :--- | :--- | :--- |
| **작업**<br>(Actions) | **1. 국내 송장 확인** (Blue Fill): `국내 배송중` 상태일 때만 노출. 클릭 시 실시간 택배 조회.<br>**2. 추가 소싱하기** (Outline): 품절 대비 또는 추가 수익을 위한 소싱처 추가. | 배송 단계별 버튼 동적 노출 |

## 3. 상세 정보 확장 (Expand Row)
행 클릭 시 하단에 펼쳐지는 상세 영역은 **3단 레이아웃**으로 구성된다.

### 3.1 정보 섹션 (Left)
*   **수령인 정보 카드**:
    - **주소**: 우편번호 포함 전체 주소 (지번/도로명).
    - **배송 메시지**: "문 앞에 놔주세요" 등 고객 요청사항.
    - **PCCC**: `P123456789012` + `[일치]` 배지. (수정 버튼 포함)
*   **국내 배송 정보 카드** (Active when Domestic Shipping):
    - **헤더**: CJ대한통운 (택배사 로고).
    - **운송장**: `509501161401` (클립보드 복사).
    - **상태**: "배달 완료 (오후 2:00)".
    - **액션**: `배송 조회` 버튼.

### 3.2 상세 내역 섹션 (Center)
*   **상품 상세**:
    - 마켓 상품명 (Link) + 타오바오 원문 상품명 (Link).
    - 옵션: "색상: 블랙 / 사이즈: L (+1,000원)".
    - 수량 x 단가 계산.
*   **비용 브레이크다운**:
    - `결제금액` (고객 결제액)
    - `- 마켓 수수료` (플랫폼 수수료)
    - `- 예상 해외배송비` (배대지 비용)
    - `- 예상 관부가세` (발생 시)
    - `= 예상 정산액` (최종 수익)
*   **소싱 이력 아코디언**:
    - 과거 소싱 시도(#1, #2...) 이력 전체 노출. (실패/환불 건 포함)

### 3.3 처리 관련 섹션 (Right)
*   **워크플로우 바로가기**:
    - `배송대행지 관리 (1)`
    - `소싱 주문 관리 (#2)`
    - `주문 히스토리`
    - `배송 추적`
*   **내부 관리 메모**:
    - Textarea + 저장 버튼. (물류 특이사항 기록용)
    - 시스템 로그와 별도로 운영자가 수동으로 남기는 메모.

## 4. 핵심 모달 상세 기능

### 4.1 배송대행지 관리 (Warehouse Modal)
"주문팡팡 안에서 배대지 업무를 끝낸다"는 컨셉.
*   **검수 사진**:
    *   도착한 실물 사진 그리드 (최대 8장).
    *   클릭 시 고해상도 뷰어 + 다운로드/공유 기능.
*   **배송비 결제**:
    *   실측 무게(kg) 및 부피 무게 기반 배송비 확정 내역.
    *   `결제하기` 버튼 연동 (예치금 차감 등).
*   **부가 서비스 신청/취소**:
    *   정밀검수, 안심포장, 돼지코 동봉 등 옵션 Toggle.
    *   비용 실시간 합산.
*   **채팅**: 배대지 전용 1:1 문의 채널.

### 4.2 소싱 주문 관리 (Sourcing Management Modal)
재주문/환불 처리를 위한 셀러 소통 허브.
*   **차수별 탭**: #1(취소됨), #2(진행중) 등으로 탭 분리.
*   **자동 번역 채팅**:
    *   [수신] 중국어 -> 한국어 자동 번역 표시.
    *   [발신] 한국어 입력 -> 중국어 자동 변환 전송.
*   **반품 가이드**: "반품 주소 획득 -> 배대지 신청서 작성" 2단계 안내 문구 상시 노출.

### 4.3 배송 추적 (Tracking Modal)
4단계 구간별 정밀 추적.
1.  **China Local**: 쑤저우 집화 -> 상하이 배송센터 -> 웨이하이 도착.
2.  **Warehouse**: 입고대기 -> 입고 -> 검수 -> 출고대기 -> 출고.
3.  **Customs**: 입항 -> 적하목록 제출 -> 심사 -> 반출 (유니패스).
4.  **Korea Local**: 허브터미널 -> 서브터미널 -> 배송출발 -> 완료.
### 4.4 국내 송장 확인 및 확정 (`DomesticTrackingConfirmModal`)
*   **진입**: 상세 내역의 `배송 조회` 버튼 또는 작업 컬럼의 `국내 송장 확인` 버튼 클릭.
*   **기능**:
    - **정보 확인**: 현재 등록된 택배사와 운송장 번호를 한눈에 확인.
    - **마켓 연동**: 마켓 송장 등록 상태를 체크하고 필요 시 등록 안내.
    - **연결**: `전체 배송 추적` 클릭 시 구간별 상세 트래킹 모달(4.3)로 즉시 전환.
