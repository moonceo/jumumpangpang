# 주문관리: 4. 배송중 (Shipping) Master Spec

## 1. 개요
현지 운송장이 등록되어 물류 이동이 시작된 시점부터 국내 고객에게 배송이 완료될 때까지의 전 과정을 관리한다. 전체 리드타임 중 가장 긴 시간을 차지하며, **고객 문의 방어(배송 조회)**와 **물류 예외 대응(오류입고, 통관지연)**이 핵심이다.

*   **URL**: `/orders/shipping`
*   **핵심 가치**: 실시간 트래킹, 배대지 통합 관리, 소싱 이력 추적, 비용 정산 시뮬레이션

## 2. 포함 상태 (Status Scope)
거의 모든 물류 단계를 포괄하며, 배송 완료 이후의 구매 확정 프로세스까지 관리한다.
*   **현지**: `현지 발송 대기중`, `현지 배송중`
*   **배대지**: `입고 대기`, `오류입고`, `입고중`, `견적 완료`, `배송비 결제 완료`, `출고 준비`, `출고 완료`
*   **국내/통관**: `국내 입항`, `국내 배송중`
*   **완료/확정**: `배송 완료`, `구매 확정 대기`, `구매 확정`

## 3. 데이터 테이블 명세 (Table Columns)

| 컬럼명 | 데이터 및 UI 명세 | 비고 |
| :--- | :--- | :--- |
| **작업** | **[국내 송장 확인]** (Blue Fill) / **[추가 소싱하기]** (Outline) | 상태에 따라 액션 버튼 동적 노출 |
| **주문일시** | `YYYY-MM-DD HH:mm` (상대 시간 병기) | 최신순 정렬 기본 |
| **상품정보** | 썸네일 + 마켓 상품명 + 옵션명 + 마켓 주문번호 (Copyable) | AI 옵션 이미지 여부 표시 |
| **처리상태** | **관리형 배지**:<br>- 현지/입고: Blue<br>- 출고/통관: Purple<br>- 국내배송: Green<br>- 오류/예외: Red | 11개 세부 상태 구분 |
| **수령자** | 성함 / 연락처 + **PCCC 배지** (확인됨/필요) | 마스킹 없음 |
| **결제/마진** | 고객 결제가격 + **예상 실마진율** (%) | 수익성 실시간 모니터링 |
| **마켓** | 마켓 아이콘 + 채널명 (네이버/쿠팡 등) | 스토어명 병기 |

## 4. 상세 정보 확장 레이아웃 (Expandable Row)
행 클릭 시 하단에 펼쳐지는 상세 영역은 **3단 그리드 레이아웃**으로 구성된다.

### 4.1 정보 섹션 (Left) - 인적 정보 및 물류 요약
*   **주문자 정보**: 구매자 성함, 연락처 표시.
*   **수령인 정보 (수정 가능)**:
    - **성함 / 연락처**: 통합 표기 및 `수정 가능` 배지 노출.
    - **주소**: 우편번호 + 기본주소 + 상세주소 (주소 검색 기능 포함).
    - **PCCC (통관번호)**: 
        - **확인됨**: PCCC 번호 노출 + 복사 버튼.
        - **필요**: "수집되지 않음" 강조 + `문자 발송` 액션 버튼.
*   **배송 정보 (Shipping 전용)**:
    - 현재 물류 상태 + 국내 송장(택배사/번호) 요약 정보.

### 4.2 내역 섹션 (Center) - 비용 및 이력
*   **상품 상세**: AI 옵션 배지, 마켓 링크, 단가/수량 요약.
*   **비용 상세 (5단계 정산 시뮬레이션)**:
    - `결제금액`: 고객이 마켓에 지불한 총액.
    - `- 마켓 수수료`: 플랫폼별 판매/결제 수수료.
    - `- 예상 해외배송비`: 배대지 실측/부피 무게 기반 확정 또는 예상 비용.
    - `- 예상 관부가세`: 품목별 관세율 적용 예상치.
    - `= 예상 정산액`: 운영자 최종 실수익 (Blue Bold).
*   **소싱 이력 (History)**:
    - 해당 주문에 대한 모든 소싱 시도(#1, #2...)를 리스트업. (매칭률, 소싱 단가, 상태 포함)

### 4.3 워크플로우 섹션 (Right) - 핵심 액션 관리
사용자가 가장 빈번하게 사용하는 기능을 배치한다. (상세 내용은 6개 워크플로우 버튼 명세 참고)
*   **내부 관리 메모**: 특이사항(오류 원인, 고객 요청 등) 기록용 텍스트 필드.

## 5. 핵심 모달 상세 기능

### 5.1 배송대행지 관리 (Warehouse Modal)
"배대지 사이트 이동 없이 주문팡팡 내에서 모든 처리 완료"
*   **운송/통관 비용**: 기본료, 수수료, 정밀검수료 등 상세 항목 노출 및 결제 연동.
*   **부가 서비스**: 정밀 검수, 안심 포장, 돼지코 동봉 등 실제 신청 상태를 Toggle UI로 관리.
*   **검수 실물 사진**: 현지에서 촬영된 사진(최대 8장) 그리드, 확대 보기, 전체 다운로드.
*   **1:1 채팅**: 배대지 현지 담당자와의 실시간 커뮤니케이션 채널.

### 5.2 소싱 주문 관리 (Sourcing Management Modal)
"중국 판매자와의 분쟁 해결 및 재주문 관리"
*   **차수별 탭 대응**: 실패한 소싱(#1)과 현재 진행 중인 소싱(#2)을 탭으로 구분하여 비교.
*   **마진 시뮬레이션**: 각 소싱처별 단가에 따른 실시간 마진 변화량 계산.
*   **반품/환불 가이드**: 반품 주소지 확보 및 배대지 신청 가이드를 상시 노출하여 운영 실수 방지.
*   **자동 번역 채팅**: 셀러와의 채팅 내역을 한국어로 번역하여 노출.

### 5.3 배송 추적 (Tracking Modal)
"전 구간 통합 트래킹"
*   1단계(중국 현지) -> 2단계(배대지 처리) -> 3단계(통관 처리) -> 4단계(국내 배송)를 하나의 타임라인으로 병합 표시.

## 6. 핵심 워크플로우 버튼 명세 (6대 기능)

주문 관리 효율화를 위해 상태별로 최적화된 6가지 핵심 버튼이 제공된다.

1.  **국내송장확인**: 현재 등록된 국내 택배사 정보를 확인하고 마켓 송장 등록 여부 가질 수 있도록 확정 팝업을 띄움.
2.  **추가소싱하기**: 현재 상품이 품절되거나 더 저렴한 소싱처를 찾았을 때, 기존 발주를 유지하면서 새로운 소싱 시도를 추가함.
3.  **배송대행지 관리**: 배대지 입고 현황 확인, 검수 사진 검토, 추가 서비스 신청 및 배송비 결제를 처리함.
4.  **소싱주문관리**: 해외 마켓 셀러(타오바오 등)와의 채팅 확인, 발주 취소/환불 요청, 재발송 요청 등을 관리함.
5.  **주문히스토리보기**: 주문 접수부터 현재까지의 모든 상태 변경 로그 및 운영자Action 기록을 타임라인으로 확인함.
6.  **배송추적**: 현지 배송부터 통관, 국내 택배까지 전 구간의 위치 정보를 상세 추적함.
