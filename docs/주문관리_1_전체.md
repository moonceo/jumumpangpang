# 주문관리: 1. 전체 (All)

## 1. 개요
서비스 내 모든 상태의 주문을 통합 조회하고 검색할 수 있는 "Control Tower" 역할을 하는 메뉴이다. 특정 상태에 국한되지 않고 전체 물류 흐름을 조망하거나, 고객 문의 시 특정 주문을 빠르게 검색하는 용도로 사용된다.

*   **URL**: `/orders` (또는 `/orders/all`)
*   **핵심 가치**: 통합 검색, 전체 주문 현황 파악

## 2. 주요 기능 상세

### 2.1 통합 검색 (Universal Search)
상단 검색바를 통해 다양한 필드를 동시에 검색한다.
*   **검색 대상**:
    *   마켓 주문번호 (마켓에서 생성된 원본 번호)
    *   주문 ID (주문팡팡 시스템 내부 고유 ID)
    *   주문자 / 수령인 성함
    *   주문자 / 수령인 연락처 (뒷자리 검색 등)
    *   상품명 (부분 일치)

### 2.2 주문 동기화 (Sync)
*   **기능**: 연동된 모든 마켓(스마트스토어, 쿠팡, 11번가 등)의 최신 주문 데이터를 즉시 수집한다.
*   **UI 동작**: `주문 불러오기` 버튼 클릭 시 로딩 스피너가 노출되며, 수집 완료 시 토스트 메시지로 "N건의 새로운 주문을 수집했습니다" 등의 피드백을 제공한다.

### 2.3 상태 필터 (Status Filter)
전체 메뉴의 가장 큰 특징은 **모든 스테이지의 주문 상태**를 필터링할 수 있다는 점이다.
*   **기본값**: 전체 보기
*   **필터 옵션**: `ORDER_STATUSES.ALL`에 정의된 **42개+** 상태 전체 노출.
    *   **신규/대기**: `신규 주문`, `통관부호 수집중`, `소싱상품 선택대기`, `결제 대기`, `결제 완료` 등
    *   **진행중**: `현지 발송 대기중`, `현지 배송중`, `입고 대기`, `오류입고`, `입고중`, `견적 완료`, `배송비 결제 완료`, `출고 준비`, `출고 완료`, `국내 입항`, `국내 배송중`, `배송 완료`, `구매 확정 대기`, `구매 확정` 등
    *   **클레임/종료**: `주문 취소됨`, `반품 완료`, `교환 완료`, `취소 요청`, `취소 처리중`, `취소 완료`, `취소 거부`, `반품 요청`, `반품 수거중`, `반품 수거 완료`, `반품 처리중`, `반품 거부`, `교환 요청`, `교환 수거중`, `교환 수거 완료`, `교환 처리중`, `교환 재배송중`, `교환 거부`
    *   **기타**: `알 수 없는 상태`

## 3. 데이터 테이블 구성
공통 데이터 테이블(`OrderTable`)을 사용하며, 특정 상태에 특화된 기능보다는 전반적인 정보를 확인하는 데 중점을 둔다.

*   **정렬**: 기본적으로 `주문일시` 최신순으로 정렬된다.
*   **작업(Action) 컬럼**: 주문의 현재 상태에 따라 적절한 액션 버튼이 동적으로 렌더링된다.
    *   예: 상태가 '신규 주문'인 행 → `발주 확인서 보기`, `마진 검토하기` 노출
    *   예: 상태가 '배송중'인 행 → `배송 추적`, `배송대행지 관리` 노출
