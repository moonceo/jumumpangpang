# 주문관리: 3. 발송대기 (Waiting)

## 1. 개요
발주는 확인(판매자 인지)했으나 아직 현지 배송이 시작되지 않았거나, 내부적으로 소싱 및 결제를 준비하는 단계이다. **현지 발송 전(Pre-delivery)**의 모든 준비 과정을 포함한다.

*   **URL**: `/orders/waiting`
*   **핵심 가치**: 소싱 매칭, 결제 관리, 가송장 처리

## 2. 포함 상태 (Status Scope)
*   `통관부호 수집중`: PCCC 미입력으로 발송 대기 중인 주문. (신규주문에서 수집 완료된 건만 넘어오는 것이 아니라, 여기서도 수집 과정을 관리함)
*   `소싱상품 선택대기`: 발주는 확인했으나 아직 매칭할 소싱 상품을 고르지 못한 상태.
*   `결제 대기`: 소싱 상품은 선택했으나 결제가 이루어지지 않은 상태.
*   `결제 완료`: 결제는 했으나 아직 셀러가 발송하지 않은 상태.
*   `알 수 없는 상태`: 시스템이 판단하기 어려운 예외 상태.

## 3. 핵심 기능 및 마켓별 규정

### 3.1 마켓별 송장 처리 (Implementation Rules)
마켓 정책상 발주 확인 후 일정 시간 내에 송장을 입력해야 패널티를 받지 않는다. 이를 위해 **가송장(임시 송장)** 프로세스가 필요하다.

*   **쿠팡/ESM**: 시스템이 **자동**으로 가송장 -> 실송장 업데이트를 처리한다. (별도 작업 불필요)
*   **스마트스토어**: 자동 업데이트가 불가능하다. 사용자에게 '작업필요' 알림을 띄우고 **수동**으로 수정을 유도해야 한다.
*   **11번가**: 가송장 입력 시 택배사가 아닌 **'직접전달'** 모드로 설정해야 한다.

### 3.2 가송장 필터 (Temp Invoice Toggle)
*   **기능**: 검색창 우측(또는 필터 영역)에 `가송장만 보기` (Show Temp Invoice Only) 스위치를 제공한다.
*   **목적**: 임시 번호가 부여된 주문만 빠르게 필터링하여 실송장 업데이트가 필요한 건을 식별한다.

### 3.3 주요 액션

#### A. 소싱 상품 등록 (Sourcing Register)
*   **상황**: `소싱상품 선택대기` 상태 등 매칭된 상품이 없는 경우.
*   **동작**: `소싱상품 등록하기` 버튼을 통해 소싱 모달을 호출하고, 알리바바/타오바오 상품 URL이나 내 장바구니 상품을 주문에 연결한다.

#### B. 직접전달 처리 (Manual Invoice)
*   **상황**: 11번가 등 특수 마켓 또는 기타 사유로 송장 번호 없이 발송 처리를 해야 할 때.
*   **동작**: `직접전달 처리하기` 버튼으로 송장 번호 입력 없이 '발송 처리' 상태로 변경한다.
