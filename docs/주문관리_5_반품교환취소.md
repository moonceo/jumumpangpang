# 주문관리: 5. 반품/교환/취소 (Claims)

## 1. 개요
고객 요청이나 시스템 오류, 배송 사고 등으로 인해 정상적인 프로세스 진행이 불가능한 "예외 주문(Exception Order)"을 전담 관리한다. 판매자에게 가장 스트레스가 되는 업무이므로, **직관적인 프로세스 가이드**와 **상태 추적**이 중요하다.

*   **URL**: `/orders/claims`
*   **핵심 가치**: 클레임 처리 프로세스 정형화, 손실 최소화

## 2. 포함 상태 (Status Scope)
클레임 유형별로 세분화된 상태 코드를 관리한다. (`ORDER_STATUSES.CLAIMS`)
*   **취소**: `취소 요청`, `취소 처리중`, `취소 완료`, `취소 거부`, `주문 취소됨`
*   **반품**: `반품 요청`, `반품 처리중`, `반품 수거중`, `반품 수거 완료`, `반품 완료`, `반품 거부`
*   **교환**: `교환 요청`, `교환 처리중`, `교환 수거중/완료`, `교환 재배송중`, `교환 완료/거부`
*   **물류 예외**: `오류입고`, `검수불합격` (배대지 입고 단계에서의 문제)

## 3. 핵심 프로세스 가이드

### 3.1 2단계 반품/교환 원칙 (Two-Step Process)
해외 구매대행 특성상 국내 쇼핑몰과 달리 반품 절차가 복잡하다. UI 상단에 다음 가이드를 상시 노출하여 실수를 방지한다.

1.  **1단계 (소싱 협의)**:
    *   `소싱주문 관리` 모달의 **셀러 채팅**을 통해 중국 판매자에게 반품 의사를 밝힌다.
    *   판매자로부터 **'반품지 주소(중국)'**와 **'수령인 정보'**를 정확히 획득한다.
2.  **2단계 (배대지 신청)**:
    *   획득한 주소 정보를 바탕으로 `배송대행지 관리` 모달에서 **'반품 신청서'**를 작성한다.
    *   이후 배대지에서 반송 운송장을 생성하고 반출 처리를 진행한다.

### 3.2 상세 기능
*   **클레임 필터**: 취소/반품/교환 유형별 탭 또는 필터를 제공하여 유형별로 모아볼 수 있다.
*   **사유 관리 섹션**:
    *   주문 상세 확장에서 **붉은색 경고 아이콘**과 함께 클레임 사유를 별도로 보여준다.
    *   예: "고객 변심 - 사이즈가 생각보다 큽니다", "오배송 - 다른 색상이 왔어요"
*   **주요 액션**:
    *   **처리 완료(강제 변경)**: 시스템 연동 없이 관리자가 강제로 상태를 '완료' 처리해야 하는 경우(예: 직접 환불 송금 등)를 대비한 기능.
    *   **배송 추적**: 반품 수거(국내) 및 현지 반송(해외) 경로 추적.
