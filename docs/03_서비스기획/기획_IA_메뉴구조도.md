# [기획] IA 메뉴 구조도 (Service IA)

본 문서는 사용자와 기획자가 시스템의 전체 구조를 쉽게 이해할 수 있도록 구성된 정보 설계도입니다.

## 1. 전체 메뉴 요약

- **Level 1**: 시스템의 핵심 대분류
- **Level 2**: 상세 기능 및 프로세스 단계
- **주요 기능**: 해당 화면에서 사용자가 수행하는 핵심 액션

---

## 2. 상세 구조도

| Level 1 | Level 2 | 설명 및 주요 기능 | URL 경로 |
| :--- | :--- | :--- | :--- |
| **대시보드** | - | 매출 현황 및 긴급 업무 요약 | `/` |
| **주문관리** | **전체** | 마켓별 모든 주문 통합 조회/검색 | `/orders` |
| | **신규주문** | **[핵심]** PCCC 검증, AI 마진 검토 및 소싱 확정 | `/orders/new` |
| | **발송대기** | 배대지 전송 및 송장 번호 입력/확정 | `/orders/waiting` |
| | **배송중** | 국내외 배송 상태 실시간 모니터링 | `/orders/shipping` |
| | **반품/교환/취소** | 입고 오류 처리 및 클레스 대응 관리 | `/orders/claims` |
| **문의관리** | - | 마켓 문의 답변 (AI 초안 지원) | `/inquiries` |
| **내정보** | **프로필** | 개인 계정 정보 및 비밀번호 관리 | `/me/profile` |
| | **마켓 연동** | 스마트스토어, 쿠팡 등 API 키 설정/연동 | `/me/markets` |
| | **플랜 관리** | 서비스 이용권 결제 및 구독 관리 | `/me/plan` |
| | **알림 설정** | 주문/문의 발생 시 알림 수신 설정 | `/me/notifications` |
| | **장부 관리** | 정산 내역 확인 및 엑셀 다운로드 | `/me/ledger` |

---

## 3. 사용자 권한 및 접근성

- **마스터 계정**: 모든 메뉴 접근 및 설정 변경 가능
- **서브 계정 (준비중)**: 주문 관리 전용 또는 문의 관리 전용 등 권한 부여 가능

---

## 4. 사이트 하단 및 유틸리티

- **공지사항**: 서비스 업데이트 및 공지 (모달 형태)
- **알림 센터**: 실시간 업무 발생 알림 (헤더 팝오버)
- **브레드크럼**: 현재 위치 "주문관리 > 신규주문" 등의 경로 표시
