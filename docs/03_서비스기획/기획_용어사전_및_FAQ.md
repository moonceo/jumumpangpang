# [기획] 서비스 FAQ 및 전문 용어 사전

주문팡팡을 이용하면서 궁금할 수 있는 질문들과 서비스에서 사용되는 주요 용어들을 정리했습니다.

## 1. 자주 묻는 질문 (FAQ)

**Q: 주문 수집은 얼마나 자주 일어디나요?**
A: 기본적으로 1시간마다 자동으로 수집되며, `대시보드`나 `주문관리` 상단의 '새로고침' 버튼을 눌러 즉시 수집할 수도 있습니다.

**Q: AI 마진 계산은 100% 정확한가요?**
A: AI는 실시간 환율과 평균 배대지 비용을 기준으로 계산합니다. 실제 지불한 배송비나 환율에 따라 소액의 차이가 발생할 수 있으니, 중요한 발주 전에는 상세 내역을 확인해 주세요.

**Q: 통관부호가 잘못되었을 때 어떻게 하나요?**
A: 시스템에서 자동으로 오류를 감지합니다. 해당 주문의 `통관부호 요청` 버튼을 누르면 고객에게 수정 링크가 발송되며, 고객이 직접 입력하면 즉시 데이터에 반영됩니다.

## 2. 전문 용어 사전 (Glossary)

| 용어 | 설명 |
| :--- | :--- |
| **PCCC** | 개인통관고유부호. 해외 직구 주문 시 세관 통관을 위해 반드시 필요한 수령인의 식별 번호입니다. |
| **소싱 (Sourcing)** | 판매할 상품을 현지(주로 중국) 도매처에서 구매하는 행위입니다. |
| **배대지** | 배송대행지. 현지에서 구매한 상품을 대신 받아 검수하고 한국으로 발송해주는 물류 거점입니다. |
| **정산예정금** | 마켓 판매가에서 마켓수수료를 제외하고 셀러에게 실제 지급될 예정인 금액입니다. |
| **마진율 (%)** | (정산예정금 - 소싱비용 - 배송비 / 정산예정금) * 100으로 계산된 수익 지표입니다. |
| **API 연동** | 마켓(네이버, 쿠팡 등)과 주문팡팡 시스템 간에 데이터를 주고받기 위한 기술적 연결입니다. |

## 3. 추가 도움말

서비스 이용 중 기술적인 문제나 정책 궁금증이 생기시면 언제든 **'고객센터'** 또는 **'문의관리'**를 통해 연락 주시기 바랍니다.
