# 주문관리: 2. 신규주문 (New)

## 1. 개요
마켓에서 주문이 수집되었으나 아직 판매자가 처리를 시작하지 않은 "미확인" 상태의 주문을 집중적으로 관리한다. 이 단계의 핵심 목표는 **주문 정보를 검증(PCCC 등)**하고 **마진을 시뮬레이션**하여 **발주(소싱)**를 확정하는 것이다.

*   **URL**: `/orders/new`
*   **핵심 가치**: 신속한 주문 인지, 마진 확보, 발주 확정 편의성

## 2. 포함 상태 (Status Scope)
*   **신규 주문**: 마켓에서 갓 수집된 초기 상태. (현재 `NEW` 필터는 이 상태만 포함)

## 3. 화면 구성 및 주요 기능

### 3.1 목록 관리 (Bulk Actions)
*   **체크박스 선택**: 테이블 좌측의 체크박스를 통해 다수의 주문을 선택할 수 있다.
*   **하단 플로팅 바 (Floating Action Bar)**:
    *   주문 선택 시 화면 하단에 검정색 바로 나타난다.
    *   **구성 정보**: "N개 주문 선택됨" 텍스트, `선택 해제` 버튼.
    *   **액션**: `일괄 발주 확인하기` (Primary Action). 클릭 시 선택된 주문들이 다음 단계(`발송대기`)로 일괄 이동된다.

### 3.2 상세 정보 확장 (Expand Row)
행을 클릭하여 펼쳤을 때, 신규 주문 단계에서 특히 중요한 정보들을 확인 및 수정할 수 있다.
*   **수령인 정보 및 PCCC 수정**:
    *   `수령자` 컬럼 또는 상세 내역에서 **수정(연필 아이콘)** 버튼을 통해 정보를 즉시 수정할 수 있다.
    *   **통관부호(PCCC)**: 미입력 또는 12자리 미만일 경우 붉은색 텍스트로 강조되며, `통관부호 요청` 버튼이 활성화되어 알림톡을 발송할 수 있다.
*   **결제 및 마진 분석**:
    *   `결제가격 - 플랫폼 수수료 = 정산예상금액`을 상세히 보여준다.
    *   예상 매입가(소싱가)와 배송비를 즉시 입력해보며 **예상 순이익**을 계산해볼 수 있다.

### 3.3 핵심 모달 (Detailed Modals)

#### A. 마진 검토 (Margin Review Modal)
*   **진입**: 개별 주문의 `마진 검토하기` 버튼 클릭.
*   **기능**:
    *   **좌측**: 주문 상품 정보 및 정산 예정액 표시.
    *   **우측 (AI 소싱)**: 타오바오/티몰 등에서 AI가 매칭한 소싱 상품 후보 리스트 제공.
    *   **시뮬레이션**: 선택한 소싱 상품의 옵션/수량/단가에 따른 최종 마진율 실시간 계산.
    *   **결정**: `소싱 진행` 버튼 클릭 시 해당 상품으로 매칭되며 다음 프로세스 준비.

#### B. 주문 취소 (Order Cancel Modal)
*   **진입**: `주문 취소하기` 버튼 클릭. (Ghost Button, Red Color)
*   **기능**:
    *   **사유 선택**: 구매 의사 취소, 품절, 배송 지연 등 마켓 표준 사유 선택.
    *   **전송**: `주문 취소하기` 실행 시 연동된 마켓 API를 통해 즉시 취소 처리 요청이 전송된다. (주의: 취소 후 되돌릴 수 없음을 경고)
