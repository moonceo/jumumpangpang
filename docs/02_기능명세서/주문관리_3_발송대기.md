# 주문관리: 3. 발송대기 (Waiting)

## 1. 개요
발주는 확인(판매자 인지)했으나 아직 해외 현지 배송이 시작되지 않았거나, 내부적으로 소싱 및 결제를 준비하는 단계이다.

*   **URL**: `/orders/waiting`
*   **공통 UI 적용**: [0_공통.md](file:///f:/dev4/jumumpangpang/docs/주문관리_0_공통.md)의 규격을 따른다.

## 2. 처리 상태 (Processing Status)
- **부제목**: "발주가 진행중인 주문을 확인하고 발주를 진행합니다."
- **검색바 플레이스홀더**: "마켓 주문번호, 주문 ID, 주문자, 수령인 정보, 상품명 검색"
- **특화 기능**:
  - **가송장만 보기 토글**: 국내 택배사 가송장 입력 여부에 따른 필터링 기능 (Switch UI).
  - **주문 불러오기**: 마켓 주문 정보를 최신 상태로 동기화하는 기능 (Refresh Button).
  - **소싱상품 등록하기**: 소싱 상품이 확정되지 않은 경우, AI 추천 목록에서 상품을 선택하고 매칭하는 기능.
  - **직접전달 처리하기**: 별도 송장번호 입력 없이 '직접전달' 방식으로 발송 처리를 수행하는 모달.
  - **결제하기**: 소싱 상품에 대한 결제를 진행하는 **3단 레이아웃(상품-배송-결제)** 기반의 상세 모달.

### 2.1 상태 필터 목록 (Status Filter Options)
상단 도구 모음의 '상태 필터' 드롭다운에서 선택 가능한 옵션:
| 상태명 | 설명 |
| :--- | :--- |
| `통관부호 수집중` | 고객에게 통관고유부호를 요청하고 대기 중 |
| `소싱상품 선택대기` | 매칭된 소싱 상품 중 하나를 선택해야 함 |
| `결제 대기` | 소싱 상품 확정 후, 해외 셀러에게 결제 필요 |
| `결제 완료` | 결제가 완료되어 현지 발송을 기다리는 상태 |
| `알 수 없는 상태` | 마켓 API 오류 등으로 상태 파싱 실패 |

### 2.2 상세 정보 (확장 레이아웃)
발송대기 상태의 주문을 확장하면 다음과 같은 상세 정보가 노출됩니다.
- **주문 상품**: 마켓 주문 정보 및 정산예상금액 요약.
- **소싱 상품**: 확정된 소싱처 상품 정보 및 **상세 비용 내역** (상품가 CNY/KRW, 소싱처 이용료, 환전 수수료, 현지 배송비).
- **마진 분석**: 정산예상금액에서 모든 비용 항목(상품가, 수수료, 배송비 등)을 순차적으로 차감하여 **예상 순이익**과 **마진율**을 계산하여 표시.
- **수령인 정보 수정**: 모달이 아닌 **인라인(Inline) 수정 폼**을 통해 수령자 명, 연락처, 주소, PCCC를 즉시 수정 가능.

![구현 결과: 발송대기 상세 확장](file:///f:/dev4/jumumpangpang/docs/screenshots/주문관리/주문관리_발송대기_상세확장_최종.png)
*   **통관부호 수집중**: PCCC 미입력으로 발송 대기 중인 주문.
*   **소싱상품 선택대기**: 발주 확인 후 매칭할 소싱 상품을 확정하지 못한 상태.
*   **결제 대기 / 결제 완료**: 소싱 결제 단계 및 셀러 발송 대기 상태.

## 3. 페이지 특화 기능

### 3.1 마켓별 송장 처리 규칙
마켓 패널티 방지를 위해 **가송장(임시 송장)** 프로세스가 핵심이다.
*   **네이버 스마트스토어**: 가송장 자동 업데이트가 불가능하므로, 사용자에게 **수동 수정**을 유도한다.
*   **쿠팡/ESM**: 시스템이 자동으로 실송장 전환을 처리한다.
*   **11번가**: 가송장 입력 시 **'직접전달'** 모드로 설정해야 패널티가 없다.

### 3.2 가송장 필터 (Temp Invoice Filter)
*   **기능**: 도구 모음에 `가송장만 보기` 스위치를 제공하여 실송장 업데이트가 필요한 건을 집중 관리한다.

## 4. 핵심 액션 (Actions)
모든 버튼은 아이코을 제거하고 텍스트를 중앙 정렬하여 아래 순서로 배치한다.

1.  **주문 히스토리 보기 (Order History)**
    - 상세 확장 영역 최상단에 배치하여 주문 흐름 파악을 최우선으로 함.

2.  **직접전달 처리하기 (Direct Delivery)**
    - 송장번호 없이 주문 상태를 처리함(11번가 등 대응).

3.  **소싱상품 등록하기 (Sourcing Registration)**
    - **조건**: 소싱 이력이 없거나 확정된 상품이 없는 경우 노출.
    - **결과**: 완료 시 버튼이 `결제하기`로 변경됨.

4.  **소싱상품 결제하기 (Payment)**
    - **조건**: 확정된 소싱 상품이 있는 경우 노출.
    - **레이아웃**: 3단 대시보드 (요약-설정-결제).
    - **레이아웃**: 벤치마킹 UI를 완벽히 구현한 **3단 대시보드 (좌측:요약 / 중앙:설정 / 우측:결제)**.
    - **좌측 (상품 요약)**:
        - **주문 상품**: 마켓 주문 정보 요약.
        - **소싱 상품**: 확정된 소싱 상품 정보 및 상세 비용(상품가, 수수료, 현지배송비) 명세.
    - **중앙 (상세 설정)**:
        - **헤더 기능**: 불필요한 필터(가송장) 및 버튼(주문 불러오기) 제거, 핵심 결제 정보에 집중.
        - **배송비 계산용 예상치**: 실중량(kg) 입력 시 **예상 배송비 및 마진율 실시간 자동 계산**.
        - **배송대행지 주문서**:
            - **배송 방법**: 항공/해운(인천/평택) 선택 (AI 추천 뱃지 표시).
            - **통관 정보**: 상품/배송비(CNY), HS Code(소싱 데이터 기반 자동 입력), 통관 방식(목록/간이 - AI 추천).
        - **부가서비스**:
            - **검수**: 정밀검수, 작동검수.
            - **포장**: AI 추천 포장(변동), 일반 포장.
            - **기타**: 콘센트, 원산지 표기.
            - **출고·운송**: 관부가세 대납, 경동택배 선불.
        - **수령인 정보**: 이름, 연락처, 주소, **통관부호(유효성 검증 시뮬레이션 적용)** 등 배송지 정보 수정 폼.
    - **우측 (결제 및 마진)**:
        - **미리보기**: 결제 수단(카드) 미리보기 및 배송비 포함 최종 비용 명세.
        - **마진 분석**: 모든 설정 비용을 반영한 최종 예상 순이익 및 마진율 실시간 계산.
        - **네비게이션**: 하단 **'다른 소싱 상품 선택하기'** 버튼을 통해 소싱 상품 선택 단계로 복귀 가능.

4.  **수령인 정보 수정 (Inline Edit)**
    - 상세 확장 영역 내 '수령인 정보' 섹션에서 [수정] 아이콘 클릭 시 활성화.
    - 별도 팝업 없이 해당 영역이 Input Field로 전환됨.

5.  **통관부호(PCCC) 및 이력 관리**
    - **PCCC 정보 모달**: 리스트에서 통관부호 클릭 시, 수집된 PCCC 정보 확인 및 수정 모달 호출.
    - **주문 히스토리**: 리스트에서 아이콘 클릭 시, 해당 주문의 변경 이력(History) 타임라인 조회.
